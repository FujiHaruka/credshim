# Development

## Definition of done

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
scripts/check-secret-exposure.sh
```

## E2E

Tests that use the real SDKs (Python, Node), the `aws` CLI v2, and `credshim doctor` (Python, Node, Go) are marked `#[ignore]` and run only when you ask for them. Install Node and `aws` with mise (`mise.toml`).

```sh
(cd crates/e2e/sdk/node && npm ci)
mise exec -- cargo test -p credshim-e2e -- --ignored
cargo test -p credshim --test dev_tools -- --ignored
```

For the recommended setup, the CI `stage-b` job installs it on Linux through `scripts/install.sh` and checks the installation and the isolation with `scripts/stage-b/verify.sh`.
