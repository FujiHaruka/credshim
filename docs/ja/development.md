# 開発

## 完了の条件

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
scripts/check-secret-exposure.sh
```

## E2E

実際の SDK（Python、Node）、`aws` CLI v2、`credshim doctor`（Python、Node、Go）を使うテストは `#[ignore]` にしてあり、明示して実行する。Node と `aws` は mise で入れる（`mise.toml`）。

```sh
(cd crates/e2e/sdk/node && npm ci)
mise exec -- cargo test -p credshim-e2e -- --ignored
cargo test -p credshim --test dev_tools -- --ignored
```

推奨構成のインストールと分離は、CI の `stage-b` ジョブが Linux で `scripts/install.sh` を通して入れ、`scripts/stage-b/verify.sh` で確かめる。
